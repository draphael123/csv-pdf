How to Use This Tool

  1. Upload Files: Click the upload area or drag and drop your CSV/Excel files. You can upload multiple files at once.
  2. Preview Data (Optional): Switch to the "Preview" tab to view your data, select columns, sort, or filter before conversion.
  3. Customize Format (Optional): Go to the "Format" tab to:
    • Enter formatting instructions in the prompt box (e.g., "landscape table with red headers")
    • Or use the format options to manually set layout, orientation, colors, and font size
  4. Advanced Settings (Optional): Use the "Advanced" tab to configure:
    • Page breaks, headers, footers, and page numbers
    • PDF metadata (title, author, subject, keywords)
    • Table options, calculations, and conditional formatting
  5. Convert: Click "Convert to PDF with Formatting" and wait for the conversion to complete.
  6. Download: Once complete, click "Download PDF" to save your file, or use "Preview PDF" to view it first.

💡 Tips: You can save your settings as a template for future use. Use keyboard shortcuts (Ctrl+Enter to convert, Ctrl+Z to undo). Multiple files will be combined into one PDF unless you choose separate PDFs.
